# ANT BMS Mini-Program Integration

This module adds an ANT BMS client to the existing battery-pack mini-program.

## Scope
- BLE scan/connect/notify/read-write
- Realtime dashboard
- Parameter browsing and guarded writes
- Protection/event logs

## Not supported in WeChat mini-programs
- Persistent background polling
- System-level push notifications
- Local file export paths
- APK/IPA download or self-update
